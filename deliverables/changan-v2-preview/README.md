## 针对参考视频的调整

参考片中的祈年殿画面具有细密的木构、真实瓦面和石材、暖色侧光与克制的慢镜头。本样片借鉴这种表现方式，不把祈年殿的明清形制、蓝色琉璃瓦或龙纹彩画套入唐代长安。

- 独立重建坊门：圆柱、柱础、门板拼缝、门钉、门环、檐下承托构件与椽子。
- 灰瓦采用重叠筒瓦几何，并增加瓦当与屋脊；不再只用带条纹的平面屋顶。
- 重新生成夯土、旧朱漆木材、灰陶与石材表面纹理；使用真实几何尺度的纹理坐标。
- 增加有接缝的石铺地、远近屋顶与院落层次。
- 暖色主光、冷色天空补光和木构高光，调整檐下曝光。软件渲染使用直接光及近似反光着色，不宣称光线追踪或与参考片等同的物理准确度。
- 暂不加入上一版的低细节树木和人物；先集中评审建筑表现。

建筑细节、材质与尺寸均为**情境演绎**；坊制文献仍见[第一版资料说明](../changan/changan-sources.md)。生成的材质不是实地扫描。用户参考视频本身没有被提交到仓库。
