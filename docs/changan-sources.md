# 《走进唐长安城》资料、证据与推演边界

本片面向高中生，使用“全城关系示意 + 坊门街景情境演绎”。不是某一年代、某一坊的测绘复原。所有材质由本项目脚本程序化生成；项目原有素材是手机和平板视频，与本题无关，因此未冒用为古建素材。

## 已实际读取的资料

公开网页的 UNESCO、Wikipedia 和 Wikisource 域名在本环境被网络策略拒绝；未将这些无法读取的页面写成已核验来源。以下文献通过现有 GitHub HTTPS 通路取得并逐段核对。Kanripo 是古籍文本转录平台；引用的是原书，并非把代码仓库当成考古报告。完整相关卷文本留存在 `out/research/`。

   - [卷六，唐宫城](https://github.com/kanripo/KR2k0092/blob/776cebf717e9ea1b95178eb559574203674e55f9/KR2k0092_006.txt)：记宫城“南即皇城”。
   - [卷七，唐皇城、唐京城](https://github.com/kanripo/KR2k0092/blob/776cebf717e9ea1b95178eb559574203674e55f9/KR2k0092_007.txt)，叶一上、八上至八下：皇城正南朱雀门“北当宫城之承天门，南当外郭之明德门”；“当皇城南面朱雀门有南北大街曰朱雀门街”；“万年领街东五十四坊及东市，长安领街西五十四坊及西市”；“棋布栉比，街衢绳直”。

## 画面如何使用这些证据

|内容|证据支持的范围|画面处理|
|---|---|---|
|全城鸟瞰、道路网格|宫城—皇城—朱雀门街的南北关系；东西两市；坊与道路的分割|持续标注“布局示意 / 街坊合并·比例简化”；外郭长宽采用近似形状，不输出可测量地图|
|街坊模块|文献记载坊制及坊内道路|合并成少量重复模块；不以屏幕模块计数推定真实坊数；院落密度与屋顶高度不作考古断言|
|走近并穿过坊门|坊门存在，有通行与管理功能|持续标注“情境演绎 / 建筑形制与尺度为推演”；门的外观、木色、柱网、灰瓦、树木、服装、天气均为视觉推演|
|坊门关闭、夜禁|有开闭门、夜禁以及例外的律文|慢慢合门作为制度说明，不声称复现某次历史事件；不把夜禁解释成坊内也一律禁行|

为教学清晰，鸟瞰略去了外围宫苑、大明宫、兴庆宫、部分河渠和寺观；东南空地仅为省略区，不描绘曲江池的准确水岸。宫城内部殿宇、市场摊列、模块高度均为示意。该图**不是完整的盛唐建筑分布或逐坊定位图**。片中不会给无从核验的坊门套用真实坊名。

街景中 1 个三维单位作为 1 米使用：眼高 1.65 m、人体约 1.65 m、门洞净宽约 4.5 m、门梁下缘约 4.09 m、坊墙高 3.3 m、门屋脊高约 6.7 m、宅屋檐高 3.65 m。这组比例只用于可信的可行走尺度，**不是出土实测尺寸**。墙体的分层纹理用于表达夯筑感，不能作为真实夯层厚度。
